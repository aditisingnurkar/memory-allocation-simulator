# Memory Allocation Simulator

## Overview

A Java Swing application that simulates the **First Fit**, **Best Fit**, and **Worst Fit** memory allocation algorithms. The simulator provides a visual representation of memory allocation, fragmentation, and algorithm performance, making it easy to compare different allocation strategies.

## Features

* Simulates **First Fit**, **Best Fit**, and **Worst Fit** memory allocation.
* Interactive Java Swing interface.
* Color-coded memory visualization.
* Displays internal and external fragmentation.
* Summary view for comparing all three algorithms.

---

## How to Use

1. Enter the number of memory blocks and processes.
2. Enter the size of each memory block and process.
3. Select an allocation algorithm.
4. View the memory allocation and fragmentation statistics.
5. Click **Summary** to compare all three strategies.
